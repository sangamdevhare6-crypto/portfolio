# Sangam Devhare — Futuristic AI/ML Portfolio

A premium, next-generation personal portfolio website built as a futuristic **AI/ML Developer Dashboard + Cyber Interface**.

## 🚀 Live Preview
Open `portfolio/index.html` directly in your browser — no server required.

## 📁 Project Structure
```
portfolio/
├── index.html            ← Main HTML
├── css/
│   └── style.css         ← All styles (glassmorphism, animations, responsive)
├── js/
│   └── script.js         ← All interactive logic
├── assets/
│   ├── images/
│   │   └── profile.jpg   ← Your profile photo
│   ├── icons/
│   └── certificates/     ← Add your certificate images here
└── README.md

git add .
git commit -m "Updated portfolio"
git push
```

## ✨ Features
- 🎬 Cinematic boot-loader startup animation
- 🌌 Interactive particle system reacting to cursor
- 🖱️ Custom futuristic glowing cursor + magnetic buttons
- 🔄 Hero role typewriter morph animation
- 🌀 3D holographic profile frame with rotating rings
- 📊 Animated skill radial/circular progress indicators
- 🃏 3D tilt cards with spotlight effects
- 📈 Number counter animations on scroll
- 🤖 AI Assistant floating panel for navigation
- 📱 Fully responsive (desktop → mobile)
- 🎨 Glassmorphism + neon glow aesthetic

## 🎨 Design System
- **Background:** Deep black/navy (#020817)
- **Primary Accent:** Cyan neon (#00f5ff)
- **Secondary:** Electric blue (#0066ff)
- **Tertiary:** Purple/Magenta gradient
- **Typography:** Orbitron (display) + Rajdhani (body) + Inter (UI)

## 📝 Customization
1. Replace `assets/images/profile.jpg` with your updated photo
2. Add real GitHub links to each project card in `index.html`
3. Add certificate images to `assets/certificates/` and link from the cert cards
4. Update the resume download link in the navbar when ready
